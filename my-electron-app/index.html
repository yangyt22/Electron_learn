首页 计数器 窗口控制 文件对话框 通知

首页 · 应用信息

以下信息由 preload 通过 contextBridge 注入，不涉及 IPC 通信：

    提示：点击顶部导航，或使用菜单栏「视图」（Ctrl+1 ~ Ctrl+5）切换页面。

    计数器 · 主进程 → 渲染进程

    菜单栏 MyElectronApp → Increment / Decrement（Ctrl+↑ / Ctrl+↓）触发主进程 webContents.send 推送。

    Current value: 0

    每次更新还会经 counter-value（单向）回传主进程，打印在启动终端里。

    窗口控制 · 渲染进程 → 主进程（invoke/handle）

    窗口对象只存在于主进程，渲染进程通过 ipcRenderer.invoke 请求主进程操作。

    文件对话框 · 渲染进程 ↔ 主进程（invoke/handle）

    系统对话框 API 只能在主进程调用，invoke/handle 把结果异步返回给渲染进程。

    结果: （无）

    通知 · 纯渲染进程（无 IPC）

    使用浏览器 Notification API，完全不经过主进程——这是「非主进程」能力的对照组。
