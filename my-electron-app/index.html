    窗口控制 · 渲染进程 → 主进程（invoke/handle）

    窗口对象只存在于主进程，渲染进程通过 ipcRenderer.invoke 请求主进程操作。

    文件对话框 · 渲染进程 ↔ 主进程（invoke/handle）

    系统对话框 API 只能在主进程调用，invoke/handle 把结果异步返回给渲染进程。

    结果: （无）

    通知 · 纯渲染进程（无 IPC）

    使用浏览器 Notification API，完全不经过主进程——这是「非主进程」能力的对照组。

    读写剪贴板 · 渲染进程 ↔ 主进程

    剪贴板属于主进程模块（require('electron').clipboard）。渲染进程通过 invoke 请求主进程读写，结果再回传——和「文件对话框」同一套路子， 区别只是拿到的不是路径而是文本内容。

    折叠面板 · 标签页

    这两类组件需要 Bootstrap 的 JS 才能交互（已经本地引入 bootstrap.bundle.min.js）。

    渲染 → 主单向（send/on）、渲染 ↔ 主双向（invoke/handle）、 主 → 渲染推送（webContents.send），以及完全不走 IPC 的纯渲染进程方案。

    页面 CSP 是 default-src 'self'， 只允许加载本应用自己的文件；同时这个工程没有打包器（没有 Vite/Webpack），所以直接从 node_modules 复制 dist 到 vendor/ 引用是最省事又安全的方式。

    CSP 没有放开 'unsafe-inline'， 行内样式与行内事件都会被拦下。所以宽度、间距全部用工具类表达， 事件全部用 addEventListener 绑定。

    标签页的内容区由 .tab-content + .tab-pane 组成，切换逻辑由 Bootstrap 的 JS 处理。

    • tab-pane 需要 fade + show + active 才能淡入
    • data-bs-toggle="tab" 与 data-bs-target 指向面板 id
    • 键盘左右方向键也能切换
